# Hotfix: restaura Livro Diário com modo extrato

Em 2026-08-30, a branch de homologação foi reposicionada para restaurar o Livro Diário anterior ao experimento de simplificação visual que removeu/alterou indevidamente o modo extrato.

Decisão de produto:

- O modo extrato deve permanecer.
- O extrato deve evoluir para filtro por conta financeira e visão consolidada.
- O Livro Diário não deve exibir um "saldo geral" ambíguo sem explicitar se é consolidado de todas as contas ou saldo de uma conta selecionada.
- A próxima evolução deve preservar o saldo acumulado do extrato e separar claramente: período, conta selecionada, consolidado e lançamentos.
